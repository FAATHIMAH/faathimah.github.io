# Fathima Nesrin — Portfolio

Complete, ready-to-upload static website. Includes the blue theme, CV, preview images and all four directly playable videos. Video 3 has been rotated 90 degrees to the left into landscape.

## Upload to another GitHub account

1. Extract this ZIP on your computer. Upload the extracted files, not the ZIP itself.
2. Sign in to the destination GitHub account and create or open a public repository. For a personal homepage, name the repository USERNAME.github.io, replacing USERNAME with that account's exact GitHub username. Other repository names also work as project websites.
3. Choose Add file → Upload files. Upload index.html, styles.css, app.js, README.md, .nojekyll and the complete assets folder. Keep the folder structure intact. index.html must be at the repository root, not inside an extra folder. Commit the upload to main.
4. Open Settings → Pages. Under Build and deployment, select Deploy from a branch. Choose main and / (root), then Save.
5. Wait for GitHub to publish the website. Its URL is shown on the Pages settings screen.

A repository named USERNAME.github.io is published at https://USERNAME.github.io/. Other repository names are normally published at https://USERNAME.github.io/REPOSITORY-NAME/.

If your file picker hides .nojekyll, enable hidden files or create an empty file with that name in the repository.

## Included files

- index.html: portfolio content and native video players
- styles.css: responsive blue styling
- app.js: menu, work filters, project dialogs and video playback coordination
- assets/FathimaNesrin_Resume_OperationsExecutive.pdf: CV download
- assets/favicon.svg: browser icon
- assets/videos/: four MP4 videos and their preview images

All videos are included with the website. Visitors do not need Instagram or Google Drive to play them. There is no build command, package installation, API key or media download step.

The previous repository's canonical and social URL tags have been removed so this copy can be hosted under the destination account. You can add the final public URL to those metadata tags after publishing.
